Paslaugos

Ką galiu padaryti jums – nuo svetainės iki duomenų bazės ar automatizuoto įrankio.

Tinklalapių kūrimas

Kuriu asmenines ir nedidelių įmonių svetaines su HTML ir CSS. Svetainės prisitaiko prie telefono, planšetės ir kompiuterio ekranų.

Python automatizavimas

Rašau skriptus, kurie atlieka pasikartojančius darbus už jus: renka duomenis iš svetainių, tvarko failus ir siunčia pranešimus.

Duomenų bazių projektavimas

Projektuoju reliacines duomenų bazes: sudarau E-R modelį, normalizuoju lenteles ir parašau reikiamas SQL užklausas.

Duomenų analizė ir grafikai

Su MATLAB apdoroju matavimų duomenis, filtruoju signalus ir pateikiu rezultatus aiškiais 2D ir 3D grafikais.

Naudojamos technologijos ir įrankiai

  • HTML ir CSS – tinklalapių struktūra ir išvaizda
  • Python
    • requests – duomenų gavimas iš svetainių
    • BeautifulSoup – HTML turinio apdorojimas
  • SQL – duomenų bazių kūrimas ir užklausos
  • Git ir GitHub – kodo versijavimas ir svetainių talpinimas
  • Visual Studio Code – programavimo aplinka

Tinklalapio kūrimo etapai

  2. Struktūros ir dizaino planavimas
  3. HTML ir CSS programavimas
  4. Testavimas skirtinguose įrenginiuose ir naršyklėse
  5. Svetainės paskelbimas GitHub Pages
